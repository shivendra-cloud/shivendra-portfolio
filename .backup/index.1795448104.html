Jarvis
03

Jarvis

Voice-controlled desktop AI assistant · Developer

  • Built a locally running assistant for hands-free PC control and conversation, detecting the “Hey Jarvis” wake word with openWakeWord (forced onto the ONNX runtime to work around a broken Windows TFLite library) and transcribing speech with faster-whisper.
  • Routes each request by intent: PC commands such as opening apps, taking screenshots, checking system status and setting volume run through pyautogui and OS-level calls limited by a YAML allowlist, while general questions go to the Groq API.
  • Built a model-waterfall fallback so the assistant keeps answering when Groq deprecates models or returns 404 errors.
  • Wrapped the pipeline in an always-on-top customtkinter interface with spoken replies, safe exit handling to prevent crashes, and a hands-free follow-up mode that waits two seconds to avoid speaker echo, then listens for five seconds before returning to sleep.
